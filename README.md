# Fitness Tracker Application

A full-stack fitness tracking application that helps users track:

- Calories consumed through meals
- Calories burnt through exercises
- Weight progress over time

## Tech Stack

- Frontend: Angular
- Backend: Node.js (Express)
- Calculation Service: Python (FastAPI)
- Database: MySQL
- Auth: JWT

## Features

- User authentication
- Meal calorie tracking
- Exercise calorie burn calculation
- Weight tracking
- Dashboard with reports
